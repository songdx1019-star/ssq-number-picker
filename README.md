# 双色球随机排除选号

一个无需安装、无需后端的双色球图形界面选号工具。下载 HTML 文件，用浏览器打开即可使用。

**仅供娱乐，不构成购买建议。随机选号不会提高单注中奖概率。**

## 使用方法

1. 下载仓库中的 `双色球选号.html`（在 GitHub 文件页面点击下载原始文件）。
2. 双击文件，用现代浏览器打开，例如 Chrome、Edge 或 Firefox。
3. 输入希望留下的注数 x，选择选号方式，点击“开始选号”。
4. 完成后查看结果，可复制全部号码或保存为 TXT 文件。

## 功能

- 自定义最终留下的注数。
- 完整随机排除与快速等概率选号两种模式。
- 实时显示生成次数、已排除数量、剩余数量及用时。
- 完整模式支持暂停、继续和停止。
- 红球、蓝球以不同颜色显示。
- 支持复制和导出结果，导出内容包含娱乐声明。
- 选号逻辑在浏览器本地运行，使用 Web Worker 处理计算。

## 选号原理

每注由 6 个不重复的红球（01–33）和 1 个蓝球（01–16）组成。红球顺序不影响组合，因此全部单注组合数为：

```text
n = C(33, 6) × 16 = 17,721,088
```

### 完整排除模式

不断从全部 n 种组合中均匀随机生成号码。第一次出现的组合计入排除，重复生成的组合不再计数。当从未出现的组合只剩 x 注时停止，将这些组合列为最终结果。

程序使用位图记录已出现的组合；界面只保留近期生成样本，所有生成号码均参与去重。日志不是完整生成记录，也不会将全部生成记录写入磁盘。

当 x 很小时，最后阶段会有大量重复生成，可能需要较长时间。关闭或刷新页面会丢失进度；停止后无法继续本次任务。

### 快速选号模式

直接从全部组合中均匀随机抽取 x 个不同组合，不实际执行排除过程。它与完整排除模式最终留下的 x 注具有相同的概率分布，通常更适合只想取得选号结果的场景。

两个模式均使用浏览器的 `crypto.getRandomValues` 获取随机数，并通过拒绝采样避免取模偏差。

## 使用限制

- x 必须是 1 到 17,721,088 之间的整数。
- 大量结果会增加内存和导出耗时；界面最多显示前 1,000 注，TXT 可导出全部结果。
- 浏览器可能限制本地文件的剪贴板访问。复制失败时可使用“保存 TXT”。
- 本工具不提供开奖预测、历史开奖查询或彩票购买服务。
